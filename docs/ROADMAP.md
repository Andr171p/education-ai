# Roadmap

## Май 2026

 - [ ] **UI/UX**
     - Реализация Web интерфейса на основе лучших LMS платформ (React)
     - Поддержка нескольких тем (светлая, тёмная, ...)

 - [ ] **Авторизация**
     - JWT based аутентификация (access + refresh)
     - Ролевая модель: `student`, `teacher`, `admin`, ...
     - Вход через login (email) + password
     - Регистрация через отправку приглашений на почту

 - [ ] **AI ядро**
     - Возможность простой ротации LLM моделей (реализуется через OpenAI интерфейс)
     - Индивидуальная адаптация учеьного материала под интересы студента
     - Генерация курса используя DeepResearch (глубокий анализ предметной области),
       теоретические/методические материалы преподавателя + интервью с преподавателем
     - AI ментор для каждого студента

 - [ ] **Серверная часть**
     - Поддержка мультимодальных блоков: текст, ссылки, видео, файлы, изображения, диаграммы, интерактивные квизы, опросы, ...
     - Практические задания разных форматов: сочинения, отправка фото/скринов, эссе, live coding, тесты, аудио, ... 


 - анализ git реопозитория студента
